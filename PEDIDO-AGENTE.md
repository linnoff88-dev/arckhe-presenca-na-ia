# Pedido pronto para colar no Claude Code ou no Codex

Abra o Claude Code ou o Codex numa pasta vazia e cole:

```
Leia o kit https://github.com/inematds/presenca-na-ia (clone se precisar) e o kit irmão
https://github.com/inematds/empresa-no-chatgpt. Quero oferecer o serviço Presença na IA para a empresa
que eu vou te descrever. Faça, nesta ordem, e me mostre cada resultado antes de seguir:
1. Copie kit/exemplo-empresa.json para kit/cliente.json e preencha com os dados que eu te passar (pergunte o que faltar).
2. Gere as 4 perguntas do diagnóstico (python3 kit/diagnostico.py perguntas ...). Eu faço as perguntas no
   ChatGPT, Gemini, Claude e Perplexity e colo as respostas; você monta um arquivo de respostas para o antes e o relatório.
3. Com o relatório, preencha kit/4-proposta.md em linguagem simples, sem prometer posição nas respostas.
4. Monte a ficha do perfil (descrição até 300 caracteres) e confira com o conferir_perfil.py do
   empresa-no-chatgpt.
Não acesse nenhuma conta, não mude DNS e não envie nada a ninguém sem eu dizer "sim".
```
